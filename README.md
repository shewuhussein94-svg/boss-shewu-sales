# Boss Shewu Sales

A modern, responsive sales website for Boss Shewu Sales.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with gradient effects
- **Product Showcase**: Display your products with pricing
- **Contact Form**: Allow customers to reach out directly
- **Smooth Navigation**: Smooth scrolling and navigation experience

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Customize the content with your products and information

## Sections

- **Header/Navigation**: Main navigation menu
- **Hero Section**: Eye-catching welcome section
- **Products**: Showcase your products
- **About**: Tell your story
- **Contact**: Get in touch form
- **Footer**: Site information

## Customization

Edit the following files to customize your site:

- `index.html` - Add your content and structure
- `styles.css` - Modify colors, fonts, and layouts
- `script.js` - Add interactive features
